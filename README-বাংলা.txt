আমার বাংলাদেশি পরিচয় — বিনামূল্যের ওয়েব অ্যাপ প্যাকেজ

ফাইল:
- index.html: মূল অ্যাপ
- manifest.webmanifest: হোম-স্ক্রিনে যোগ করার তথ্য
- sw.js: মৌলিক অফলাইন ক্যাশিং

প্রকাশের সহজ পদ্ধতি (GitHub Pages):
1. GitHub.com-এ অ্যাকাউন্ট খুলুন/লগইন করুন।
2. নতুন repository তৈরি করুন; নাম দিতে পারেন amar-bangladeshi-porichoy।
3. repository-তে Add file > Upload files থেকে এই ZIP-এর ভেতরের সব ফাইল আপলোড করুন (ZIP ফাইলটি নিজে নয়)।
4. Commit changes করুন।
5. Settings > Pages-এ যান।
6. Build and deployment-এ Deploy from a branch নির্বাচন করুন।
7. Branch হিসেবে main এবং folder হিসেবে /(root) নির্বাচন করে Save করুন।
8. কয়েক মিনিট পরে Pages পেজে দেওয়া প্রকাশিত লিংক খুলুন।

নোট:
- প্রকাশিত সাইটের লিংক আলাদা হবে; এটি এখনো স্বয়ংক্রিয়ভাবে অনলাইনে প্রকাশ করা হয়নি।
- GitHub Pages সাধারণত public repository-র জন্য বিনামূল্যে।
- অ্যাপটি বর্তমানে ব্রাউজারেই পরিচয় কার্ড বানায়; তথ্য কোনো ডাটাবেসে জমা হয় না।
- কার্ড ডাউনলোডটি SVG ফরম্যাটে হয়, যা অনেক ফোনে ছবি হিসেবে দেখা যায়; প্রয়োজনে PNG রূপান্তর ফিচার পরে যোগ করা যাবে।
- Google Fonts ব্যবহারে ইন্টারনেট সংযোগ থাকলে বাংলা ফন্ট আরও সুন্দর দেখাতে পারে।
